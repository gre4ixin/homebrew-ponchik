# Ponchik for the Mac

[Ponchik Bridge](https://ponchik-app.netlify.app/mac/) links the Ponchik iPhone app with the AI agent on your Mac, directly over the local network.

```bash
brew install --cask gre4ixin/ponchik/ponchik-bridge
```

Or download `PonchikBridge.zip` from the [latest release](https://github.com/gre4ixin/homebrew-ponchik/releases/latest). The app is signed with Developer ID and notarized by Apple.
